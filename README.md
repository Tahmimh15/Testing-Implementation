# Testing-Implementation
Contains Test Case Report of a Checkout process of an E-Commerce Website. The objective of this test case document is to validate the complete e-commerce purchase journey of a user starting from product selection and add to cart, followed by cart calculation, coupon application, checkout,
authentication, 2FA/security validation, payment, inventory update, analytics tracking, and post-order details consistency.

This is a demo of a comprehensive Test Case document. Emphasis has been kept to comply by the business logic (for the cart updates and discount coupon changes, and also for the usablity and convenience of the user).
